# Icons

The icons of the sites' pages ([Frontend](../../../../docs/design/frontend.md),
Icons), one SVG file each, copied unchanged from the release named:

- `lucide/`: Lucide 1.57.0, from `lucide-icons-1.57.0.zip` of
  <https://github.com/lucide-icons/lucide/releases/tag/1.57.0>, under
  the ISC license in `lucide/LICENSE`.
- `octicons/`: GitHub's mark, `icons/mark-github-16.svg` of Octicons
  v19.33.0 (<https://github.com/primer/octicons>), under the MIT license
  in `octicons/LICENSE`.

A page names an icon by its directory and its file name, `lucide:info`
for `lucide/info.svg`. A new icon is copied from the release above, or
all of them from a newer one, with this file's version changed.
