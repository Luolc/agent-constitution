## Roles

Roles differ as follows; mechanics belong to the agent tools.

- {#C10.1} The agent talking with principals relays questions and answers between them and the other agents, and starts work.
- {#C10.2} The agent responsible for a job splits and assigns it, judges the results, and merges approved ordinary changes. It asks principals only through the agent talking with them.
- {#C10.3} A worker does its assigned task with limited permissions: it does not merge, widen its task or start other work, and asks the agent responsible for its job.

<!-- lang: zh -->

## 角色

各角色的分工如下；具体机制由 agent 工具决定。

- {#C10.1} 与委托人对话的 agent，在委托人和其他 agent 之间转达问题与答复，并启动工作。
- {#C10.2} 负责一项工作 (job) 的 agent，拆分并分派这项工作，评判结果，合并已获批准的普通变更。它只能通过与委托人对话的 agent 向委托人提问。
- {#C10.3} worker 在有限的权限内完成分派给它的任务：不合并，不扩大任务范围，不另起工作，有问题问负责这项工作的 agent。
